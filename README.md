# NECCIAL — Descargas oficiales

**NECCIAL** es la plataforma de agentes de inteligencia artificial de **Neccial Agency** para Windows.
Su primer agente atiende a tus clientes por WhatsApp con IA y deriva a una persona cuando hace falta.

## Descargar

➡️ **[Descargar la última versión](https://github.com/Aaron446688/neccial-releases/releases/latest)**:
en la página que se abre, elige el archivo `NECCIAL-Setup-….exe`.

- Requiere Windows 10 u 11 (64 bits).
- Si Windows muestra «Windows protegió tu PC», pulsa **Más información → Ejecutar de todas formas**.
- Una vez instalado, NECCIAL **se actualiza sola**: no hace falta volver a esta página.

## Importante

- Tus conversaciones, tu sesión de WhatsApp y tu API key se guardan **solo en tu computadora**.
  Actualizar o desinstalar NECCIAL no las borra.
- NECCIAL usa una integración **no oficial** de WhatsApp (WhatsApp Web), no la API oficial de Meta.
  Úsala para atender a tus clientes, nunca para enviar mensajes masivos o no solicitados.

Este repositorio contiene solo los instaladores publicados.
